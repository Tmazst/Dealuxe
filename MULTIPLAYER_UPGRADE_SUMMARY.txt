Important notes & assumptions
- The server uses SQLite by default (see `init_db`); the provided SQL migration is SQLite-formatted. If you migrate to MySQL/Postgres later, adjust types/indices accordingly.
- The `Move` model persists JSON blobs for payload and snapshots; consider normalizing if you need queryable move fields.
- The SocketIO server remains authoritative for real-time events; the REST endpoints remain for existing single-player/human_vs_ai flows.
- Masking: server now always sends per-player masked states at game start and on updates to avoid leaking opponent hands.
